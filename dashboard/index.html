아직 게시된 영상이 없습니다. 기획된 —편 가운데 첫 롱폼을 게시하면 조회수와 개선 진단이 이 화면에 채워집니다.

지금까지 —편을 게시해 조회수 —회를 얻었습니다. 아래 개선 과제를 높음 순서대로 처리하세요.

데이터: 유튜브 영상 저장소 시트. 영상 추가와 상태 변경은 시트에서 하면 이 화면이 열 때마다 새로 읽습니다.

개선 과제

시트의 상태와 지표를 기준으로 자동 진단합니다. 기준: 클릭률 4% 미만, 롱폼 지속률 35% 미만, 쇼츠 지속률 70% 미만, 조회 대비 링크 클릭 0.5% 미만, 퍼널 목표(문제인식 60 · 방법 30 · 제품 10)와 15%p 이상 차이, 롱폼 1편당 쇼츠 3편 미만.

주간 조회수 추이

시트의 주간성과 탭을 브랜드별 선으로 그립니다.

아직 주간 기록이 없습니다. 매주 월요일 날짜로 브랜드별 조회수를 주간성과 탭에 한 줄씩 적으면 추이가 그려집니다.

영상 저장소

제목을 누르면 유튜브 영상이, 영상 파일 링크가 있으면 원본이 열립니다. 머리글을 누르면 정렬됩니다.

지표 정의와 데이터 채우는 법
노출 클릭률(CTR)
썸네일이 노출된 횟수 중 클릭된 비율. YouTube Studio 분석에서 영상별로 확인합니다.
시청 지속률
영상 길이 대비 평균 시청 비율. 쇼츠는 반복 재생으로 100%를 넘을 수 있습니다.
링크 클릭
설명란 UTM 링크로 사이트에 들어온 수. 사이트 분석 도구에서 옮겨 적습니다.
자동 갱신
시트에 youtube_stats.gs Apps Script를 설치하면 조회수, 좋아요, 댓글이 매일 채워집니다.
빠진 것
유튜브 커넥터가 없어 이 화면이 유튜브를 직접 조회하지는 않습니다. 모든 수치는 시트를 거칩니다.
