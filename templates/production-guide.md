# 영상 제작 가이드 (에이전트 → 사람/툴 핸드오프)

에이전트팀은 **기획·대본·쇼츠 구성·썸네일·메타데이터·업로드·분석**을 맡고,
**영상 촬영/편집/렌더**는 아래 중 한 방식으로 진행합니다. 처음엔 A로 시작해 B로 자동화 비중을 늘리는 걸 권장합니다.

## A. 사람 + 편집 툴 (초기 추천)
1. script.md의 내레이션 열을 녹음 (본인 목소리 또는 TTS)
2. 화면/B-roll 열대로 화면 녹화 (결제 연동 데모, 앱 화면)
3. Vrew / CapCut / Premiere로 컷 편집, 자동 자막 → 자막 강조 열 반영
4. 쇼츠: 롱폼 원본에서 ✂️ 구간을 9:16으로 리프레임 + 훅 텍스트 상단 고정
5. `final.mp4`, `shorts_1.mp4`~`shorts_3.mp4`로 에피소드 폴더에 저장

## B. 반자동 파이프라인 (확장)
| 단계 | 도구 예시 |
|---|---|
| 한국어 TTS | 타입캐스트, ElevenLabs, 클로바 더빙 (상업적 이용 라이선스 확인) |
| AI 아바타 | HeyGen, D-ID (→ `containsSyntheticMedia: true`) |
| 템플릿 렌더 | Remotion 또는 ffmpeg — 쇼츠 자막/훅 템플릿화 |
| 배경 이미지 | 이미지 생성 AI (thumbnail.md 프롬프트 사용) |

## 스펙
- 롱폼: 1920×1080, 30fps, H.264, -14 LUFS
- 쇼츠: 1080×1920, 60초 이하(권장 30~55초), 하단 20%·우측 15%에 자막 금지(UI 가림)
- 썸네일: 1280×720 PNG/JPG, 2MB 이하
- 음악: 유튜브 오디오 보관함 또는 라이선스 보유 음원만
